# 03 - Šejderi i teksture

Funkcija i klase za rad sa šejderima i učitavanje tekstura su u zasebnim `.hpp` i `.cpp` fajlovima

Šejderi se učitavaju iz fajlova s diska

Šejderi transliraju jedinični kvadrat na pozicije kvadranata

Shift + K + (rgb) menja boju K-tog kvadranta 

Svaki kvadrant je obojen različitom teksturom

Shift + K + t pomeša boju K-tog kvadranta sa njegovom teksturom

Shift + (L|N) menja način filtriranja svih tekstura

(COMING SOON) Automatska rekompilacija šejdera
